🎮 → 🌐 游戏聊天上云

模组监听到游戏内聊天、玩家死亡、加入和退出后，用异步 POST /api/mc/ingest 上报（X-MC-Secret 共享密钥鉴权），Worker 写入 DO，再通过 WebSocket 即时广播给所有网页；死亡次数同时累加进死亡榜。

🌐 → 🎮 网页消息进游戏

面板服没有公网 RCON 端口，所以由模组定时轮询 GET /api/mc/poll?after=时间戳 拉走网页新消息，在游戏里用 tellraw 显示成 [网页] 消息。

  • 网页端发言需要登录，游客只能看；消息长度前后端都做校验
  • 模组所有请求都是异步的，不阻塞游戏主线程；Worker 挂了游戏内聊天照常进行
  • 上报的游戏用户名按正版规则校验（3–16 位字母数字下划线）
  • 网页标签切到后台时不发心跳、不轮询，省流量省电

🔗 游戏端 Fabric 模组开源在 github.com/AaronXieA/XRWebMC_Bridge
